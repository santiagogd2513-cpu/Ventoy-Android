# Colombia 2015 — Android
Godot 4 mobile Vulkan prototype. Open project.godot with Godot 4. Touch the screen or use arrow keys to explore the procedural corridor. This is synthetic terrain, not a geographic reconstruction. No historical assets or elevation datasets have been imported. Android export requires matching Godot templates, Android SDK and JDK. No APK has been tested.
Phase 1 remaining: licensed DEM and historical road alignment, towns, vegetation, PBR assets, weather, collision, asynchronous streaming and device profiling.
